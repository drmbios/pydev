NEW / QUANTUM HOSTS + PQC

Real capabilities.
Clear boundaries.

Five new C11 and Python tools for classical Linux/macOS hosts: OpenSSL-backed post-quantum keys, bounded circuit validation, ideal simulation, and memory planning. No physical QPU or quantum RNG is implied.

27
PQ

pqcheck

Inventory local OpenSSL KEM and signature algorithms. Check for ML-KEM and ML-DSA; availability is not a security certification.

pqcheck
28
KEY

pqkey

Generate ML-KEM or ML-DSA keys with OpenSSL 3.5+. New owner-only directory, no overwrite, no classical fallback. Private keys are unencrypted: protect them.

pqkey ML-KEM-768 pq-keys
29
QASM

qasmcheck

Validate a documented OpenQASM 2 subset and report qubits, gates, and dependency depth. Bounded to 20 qubits and 2,048 gates.

qasmcheck examples/bell.qasm
30
|ψ>

qsim

Simulate ideal circuits on a CPU and print basis-state probabilities. Up to 10 qubits; no shots, noise model, or hardware backend.

qsim examples/bell.qasm
31
RAM

qbudget

Estimate dense complex128 statevector memory without allocating it. Thirty qubits need 16 GiB of payload, before runtime overhead.

qbudget 30
UPGRADED
256

randpass --quantum

Generate 256 bits of OS-random entropy as 64 hex characters. A high-entropy secret—not a quantum RNG, cipher, or automatic protocol upgrade.

randpass --quantum

For Linux control hosts, pair these with coreinfo, syswatch, procexp, clockres, lsx, Antivermis, and structured file/system evidence. They inspect classical resources, not qubits or laboratory pulse timing.

05 / BUILT DEFENSIVELY

Inputs are hostile.
Tools should be calm.

These utilities assume files can be oversized, strings malformed, and arguments malicious. Limits are part of the product—not an afterthought.

Explore the abuse tests ↗
  • 16–64 MiB
    Bounded file reads

    General readers cap input at 16 MiB; Antivermis defaults to 32 MiB and hard-caps files at 64 MiB.

  • 128
    Validated JSON depth

    Grammar, nesting, and output growth are checked before rendering.

  • execvp
    No command shell

    Package arguments never become executable shell syntax.

  • ASAN
    Memory checked

    Sanitizers, special-file rejection, and symlink tests run across the suite.
